# Eduardo Duarte — Galeria Fotográfica

Site pessoal e não comercial para apresentar fotografias feitas com Samsung S24+ e editadas por Eduardo Duarte.

## Desenvolvimento

Execute `node server.js` na raiz do projeto. O servidor usa somente módulos nativos do Node.js e escuta na porta `3000` (ou na variável de ambiente `PORT`).

## Fotos

A primeira versão usa molduras de espera, claramente identificadas, em vez de fotos genéricas. Quando Eduardo enviar as imagens, elas poderão substituir esses espaços em `index.html`; os estilos de moldura estão em `styles.css`.
